Privasi

Poni tidak punya akun, analitik, atau pelacakan. Hampir semua yang ditampilkannya dibaca di Mac Anda dan tetap di sana. Halaman ini mencatat beberapa saat Poni tersambung ke internet, dan alasannya.

Tetap di Mac Anda

  • Acara kalender dan pengingat, dibaca lewat macOS dan tidak pernah disalin ke tempat lain.
  • Riwayat clipboard, Shelf, catatan dan timer, disimpan di folder dan pengaturan Poni sendiri.
  • Pratinjau kamera di Cermin. Tidak ada yang direkam atau disimpan.
  • Aplikasi mana yang memakai kamera atau mikrofon: Poni hanya bertanya ke macOS apakah sedang menyala.
  • Folder Downloads, dipantau hanya untuk progres.
  • Pemakaian Claude Code dan Codex, dijumlahkan dari log mereka di Mac Anda.

Tersambung ke internet, hanya ke

  • GitHub, sekali sehari, untuk memeriksa update Poni dan memuat galeri plugin.
  • Gumroad, saat Anda mengaktifkan lisensi Poni Pro dan sesekali untuk memeriksanya.
  • Open-Meteo untuk cuaca dan pencarian tempat, serta Aladhan untuk jadwal sholat, dengan kota yang Anda pilih.
  • LRCLIB, dengan judul dan artis lagu, untuk mencari lirik tersinkron.
  • Layanan kurs dan harga kripto, bila Anda memasang plugin tersebut.
  • cursor.com, hanya bila Anda menyalakan pemakaian Cursor di Pemakaian AI, memakai login Cursor yang sudah ada di Mac Anda.

Lewat Wi-Fi Anda sendiri

  • Dari HP di Shelf menjalankan server kecil di jaringan lokal selama terbuka, dengan tautan sekali pakai. File berpindah dari HP ke Mac Anda, tidak ke tempat lain.

Plugin

  • Plugin dari galeri atau buatan Anda meminta setiap izin (internet, kalender, clipboard dan lainnya) saat pertama membutuhkannya, dan bisa Anda cabut kapan saja di Pengaturan.

Terakhir diperbarui November 2026. Ada pertanyaan? Buka issue di repositori rilis.
