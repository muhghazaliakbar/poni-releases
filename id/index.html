Arahkan kursor atau ketuk notch

Notch di MacBook Anda bisa lebih dari sekadar menutupi kamera. 

Poni menaruh musik, timer fokus, jadwal hari ini, cuaca dan jadwal sholat tepat di bawah kamera. Arahkan kursor ke notch dan semuanya terbuka. Tambah plugin dari galeri, atau tulis sendiri dengan JavaScript.

Aktivitas sistem

Saat notch tertutup, sayapnya tetap bekerja

Volume, kecerahan layar dan baterai tampil sebentar di kiri-kanan notch. Coba geser atau ketuk tombol di bawah: notch kecil itu merespons seperti di Mac Anda.

Ketuk tombolnya, atau tekan ⌃⌥⌘N di keyboard. Selama terbuka: ← → atau 1–9 pindah tab, Esc menutup.

SDK plugin

Tulis plugin sendiri, dalam JavaScript yang Anda kenal

Satu folder berisi manifest.json dan main.js. Plugin tidak menggambar UI sendiri: ia mengembalikan UI deklaratif yang dirender native oleh SwiftUI, jadi semuanya terasa seperti bagian dari macOS.

Memasang versi beta

Beta ini belum dinotarisasi Apple, jadi macOS menahannya saat pertama dibuka. Konfirmasi ini cukup sekali; update berikutnya terpasang sendiri.

Panduan lengkap dan cara memeriksa tanda tangan aplikasi ada di INSTALL.id.md.

  1. 1

    Unduh DMG, lalu seret Poni ke Applications.

  2. 2

    Buka Poni.

    macOS menampilkan pesan bahwa Poni tidak dibuka. Klik Done.

  3. 3

    Buka System Settings, lalu Privacy & Security.

    Gulir ke bawah, klik Open Anyway, lalu masukkan password Mac Anda. Di macOS 14 Sonoma, cukup klik kanan Poni di Applications lalu pilih Open.
