Membuat plugin Poni

Plugin adalah satu folder berisi manifest.json dan main.js. Anda menulis JavaScript biasa yang mengembalikan susunan komponen; Poni menggambarnya di notch dengan tampilan macOS. Tidak perlu Xcode, build, atau npm.

Mulai

  1. Pasang Poni dan buka sekali.
  2. Unduh template plugin, lalu ekstrak foldernya ke ~/Library/Application Support/Poni/Plugins/. Di Finder: Go → Go to Folder, lalu tempel alamat itu.
  3. Plugin langsung muncul sebagai tab baru. Ubah main.js, simpan, dan notch memuat ulang plugin itu saat itu juga.

Keluaran console.log, error JavaScript dan peringatan lain tampil di Pengaturan, di halaman plugin Anda, bagian Konsol. Jika manifest.json tidak bisa dibaca, plugin tampil di bagian Gagal dimuat di sidebar Pengaturan beserta alasannya.

Isi template:

halo/
  manifest.json   identitas, ikon, izin dan pengaturan plugin
  main.js         kode plugin

manifest.json

{
  "id": "com.namaanda.halo",
  "name": "Halo",
  "version": "1.0.0",
  "author": "Nama Anda",
  "description": "Satu kalimat tentang apa yang dilakukan plugin ini.",
  "symbol": "lucide:hand",
  "permissions": ["network"],
  "refreshInterval": 1,
  "order": 50
}
KolomArti
idWajib. Unik, huruf kecil, berbentuk domain terbalik seperti com.namaanda.halo. Awalan app.useponi. dipakai plugin resmi.
nameWajib. Nama yang tampil di tab dan Pengaturan.
versionSeperti 1.2.0. Galeri memakainya untuk menawarkan pembaruan.
author, descriptionTampil di galeri dan Pengaturan.
symbolIkon tab: lucide:<nama> dari Lucide, atau nama SF Symbols.
permissionsIzin yang dibutuhkan, lihat Izin.
refreshIntervalDetik antara render() otomatis. Bawaan 1, paling cepat 0,25.
orderUrutan tab, angka kecil lebih dulu. Pengguna tetap bisa menyusun ulang.
mainNama berkas kode, bawaan main.js.
settingsDaftar pengaturan; Poni membuat formulirnya. Lihat di bawah.
localesOpsional. Terjemahan teks manifest per bahasa, lihat Bahasa.

Pengaturan

Tulis daftar pengaturan di manifest; Poni menampilkan formulirnya di jendela Pengaturan, menyimpan nilainya, dan memberi tombol untuk kembali ke nilai bawaan.

"settings": [
  { "key": "city", "type": "text", "label": "Kota", "default": "Jakarta", "placeholder": "Jakarta" },
  { "key": "minutes", "type": "number", "label": "Durasi", "default": 25,
    "min": 5, "max": 120, "step": 5, "help": "Dalam menit" },
  { "key": "lyrics", "type": "toggle", "label": "Tampilkan lirik", "default": true },
  { "key": "unit", "type": "select", "label": "Satuan", "default": "c",
    "options": [{ "value": "c", "label": "Celsius" }, { "value": "f", "label": "Fahrenheit" }] }
]

Jenis yang tersedia: text, number, toggle dan select. Baca nilainya dengan notch.settings.get('city') atau semuanya sekaligus dengan notch.settings.all(). Saat pengguna mengubah nilai, Poni memanggil onSettingsChanged(key, value) lalu render().

Bahasa

Poni tersedia dalam bahasa Inggris (bawaan) dan Indonesia. Tulis teks di manifest (name, description, serta label, help, placeholder dan label pilihan di settings) dalam bahasa Inggris, lalu tambahkan terjemahannya di locales.id. Kolom yang tidak diterjemahkan memakai teks bahasa Inggris.

"locales": {
  "id": {
    "name": "Catatan",
    "description": "Catatan singkat di notch.",
    "settings": {
      "showStats": { "label": "Tampilkan grafik 7 hari" },
      "unit": { "label": "Satuan", "options": { "c": "Celsius", "f": "Fahrenheit" } }
    }
  }
}

Kunci di bawah settings adalah key pengaturan; options memetakan value pilihan ke labelnya.

Di main.js, notch.locale berisi bahasa aplikasi saat ini: "en" atau "id". Nilainya berubah saat pengguna mengganti bahasa, lalu render() dipanggil lagi. Karena itu, susun teks di dalam render(), jangan saat plugin dimuat.

var TEXT = {
  en: { title: 'Hello!' },
  id: { title: 'Halo!' }
};

function render() {
  var t = TEXT[notch.locale] || TEXT.en;
  return ui.text(t.title, { style: 'title' });
}

Fungsi di main.js

Definisikan fungsi yang Anda perlukan; semuanya opsional kecuali render.

FungsiKapan dipanggil
init()Sekali, saat plugin dimuat.
render()Setiap refreshInterval, setelah aksi, timer atau fetch. Kembalikan susunan komponen ui.*.
compact()Bersama render(). Kembalikan { symbol, text, color, wide, image, equalizer } untuk tampil di samping notch saat tertutup, atau null. wide: true memberi ruang untuk teks lebih panjang, image menampilkan gambar kecil (misalnya artwork) sebagai ganti simbol, dan equalizer: true menambah bar equalizer yang bergerak.
onAction(action, value)Tombol diklik, atau isian dikirim dengan Return.
onSettingsChanged(key, value)Pengaturan diubah. key bernilai null saat semua pengaturan dikembalikan ke bawaan.

style pada teks
largeTitle (34), title (17 bold), headline (15 semibold), body (15), callout (14), caption (13), footnote (12), dan versi angka mono, monoFootnote, monoHeadline, monoTitle, dalam huruf Onest dan JetBrains Mono seperti halaman ini. Teks yang isinya angka (jam, hitung mundur, harga) bergulir saat berubah, seperti jam sistem.
align pada vstack
leading, center, trailing.
Warna
primary, secondary, tertiary, accent, blue, green, red, orange, yellow, purple, pink, teal, mint, amber, rose, white/55 (putih 55 %), atau hex #RRGGBB.
Ikon
Tulis lucide:<nama> untuk ikon Lucide (seperti di halaman ini) atau nama SF Symbol. fill: true mengisi ikon. animation: spin (berputar), drift (bergoyang), pulse (berdenyut), bob (naik-turun). Berlaku juga untuk symbol di manifest, tombol, dan compact().
stagger: true
Anak-anak tumpukan masuk bergantian saat halaman dibuka: baris dari kiri pada vstack, kartu dari bawah pada hstack.
background dan fill
background memberi kotak berwarna tipis dengan sudut membulat; fill: true melebarkan tumpukan selebar notch.

Izin

Plugin hanya bisa memakai API yang izinnya ditulis di permissions dan disetujui pengguna.

  • Plugin dari galeri mendapat izinnya saat pengguna menyetujui pemasangan.
  • Plugin yang dipasang sendiri ditanya saat pertama kali memakai sebuah izin. Selama dialog terbuka, panggilan mengembalikan null atau false; plugin digambar ulang setelah pengguna menjawab.
  • Pengguna bisa mencabut atau memberi izin kapan saja di Pengaturan, di halaman plugin.
  • API yang izinnya tidak ditulis tidak berjalan: notch.fetch memberi error yang menyebut izin yang kurang, API lain mengembalikan null.

Pilihan: network, media, notifications, clipboard, calendar, system, ai-usage, camera (untuk ui.camera()), reminders.

Batasan

  • Setiap plugin berjalan di JavaScriptCore tersendiri dan tidak bisa membaca variabel plugin lain.
  • Tidak ada DOM, require, import atau fetch bawaan browser; gunakan notch.fetch.
  • Setiap panggilan ke plugin dibatasi setengah detik. Yang lebih lama dihentikan; tiga kali dalam semenit membuat plugin dihentikan sementara sampai Anda menyimpan perbaikan.
  • Simpan data yang perlu bertahan dengan notch.storage. Variabel biasa hilang saat plugin dimuat ulang.

Contoh

Penghitung dengan sayap

var count = notch.storage.get('count') || 0;

function render() {
  return ui.vstack([
    ui.text(count + ' gelas air hari ini', { style: 'title' }),
    ui.hstack([
      ui.button('Minum', 'add', { symbol: 'lucide:droplet', style: 'primary' }),
      ui.button('Ulang', 'reset')
    ])
  ]);
}

function compact() {
  return count ? { symbol: 'lucide:droplet', text: count + ' gelas', color: 'blue' } : null;
}

function onAction(action) {
  count = action === 'add' ? count + 1 : 0;
  notch.storage.set('count', count);
}

Data dari internet

Butuh "permissions": ["network"]. Ambil data saat dimuat dan setiap 10 menit; render() hanya menggambar apa yang sudah ada.

var rate = null, error = null;

function load() {
  notch.fetchJSON('https://open.er-api.com/v6/latest/USD', function (json, err) {
    error = err;
    if (json) rate = json.rates.IDR;
  });
}

function init() {
  load();
  setInterval(load, 10 * 60 * 1000);
}

function render() {
  if (error) return ui.text('Gagal memuat: ' + error, { color: 'red' });
  if (!rate) return ui.text('Memuat kurs…', { style: 'caption' });
  return ui.row('1 USD', 'Rp ' + Math.round(rate).toLocaleString('id-ID'), { symbol: 'lucide:circle-dollar-sign' });
}

Kirim ke galeri

Plugin di galeri bisa dipasang semua pengguna Poni dengan satu klik. Daftar galeri ditandatangani, jadi setiap plugin diperiksa sebelum masuk.

  1. Periksa plugin Anda: id dan version terisi benar, ikon SF Symbol ada, setiap API yang dipakai punya izinnya, tidak meminta izin yang tidak dipakai, dan Konsol bersih dari error.
  2. Unggah folder plugin ke repositori publik atau sebagai zip.
  3. Buka issue berisi tautan ke plugin, apa fungsinya, dan kenapa izinnya dibutuhkan. Setelah ditinjau, plugin masuk ke galeri. Untuk pembaruan, kirim versi baru dengan version yang dinaikkan; pengguna mendapat tombol Update di galeri.
